# Synthetic source data

These files were generated for this demonstration; no real customer information is included.

- `customers.csv`: 150 customers
- `products.csv`: 30 products
- `orders_batch_01.csv`: 1,604 source orders (including four intentionally invalid rows)
- `orders_batch_02.csv`: 402 rows (400 new valid orders, one updated version of an existing order, one intentionally invalid row)

Keep all four files in the Fabric Lakehouse folder `Files/source`. The first ingest uses batch ID `01`; the optional later ingest uses batch ID `02`.
