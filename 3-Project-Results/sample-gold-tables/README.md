# Generated sample Gold tables

The three CSVs and the quality report were produced by the **verified local Python reference pipeline** from synthetic retail data. They are **not exports from an executed Microsoft Fabric workspace**.

- `gold_daily_sales.csv` — revenue, orders, and units by date
- `gold_product_performance.csv` — revenue, orders, and units by product
- `gold_customer_360.csv` — customers including zero-order customers
- `quality_report.json` — counts, rejected rows, and revenue reconciliation

See the root README for a business summary and the Fabric setup guide to reproduce the corresponding Delta tables in your own workspace.
